# Store screenshots

Play Store assets, generated from real captures of the dev build on a Pixel 9 emulator (1080x2424).

| File | Use |
|---|---|
| `01`–`05-*-1080x1920.png` | Phone screenshots, in listing order (24-bit PNG, no alpha) |
| `feature-graphic-1024x500.png` | Play Store feature graphic |
| `raw/` | Unframed source captures, 1080x2424 |

Story: no account or cloud, passphrase, whole folder, recipient key, secure delete.

Palette: paper `#F5F3EF`, ink `#2A2723`, safe green `#2D6B54`. Headline font: Manrope 800.
Logo source: `assets/brand/latch-mark.svg`. To retake a slide, recapture the raw screen and re-render it into the same frame; the framing is a neutral black phone on the paper background.
