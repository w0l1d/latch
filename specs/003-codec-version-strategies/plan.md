# Implementation Plan: Codec Version Strategies

## Summary

Restructure `MyencCodec` header handling into a version-dispatching façade plus one strategy
object per registry version. v1's decode/encode body moves verbatim into `_V1Strategy`; the
façade keeps the version-independent prefix (length, magic, version gate) and dispatches.
Neutrality is proven by committed artifacts generated with the pre-refactor code (header byte
corpus + full-file compatibility corpus with negative fixtures), which must pass **unedited**.
Machinery is proven by the totality invariant (dispatch table covers the registry exactly) and
the rewrap round-trip guard. Four commits, each independently reviewable:

1. **Fixtures + tests** (generated by the untouched code; must be green on the base).
2. **Pure extraction** (v1 body moves; freeze + golden + corpora pass unedited — acceptance).
3. **Machinery** (contract, dispatch table, totality test, rewrap test).
4. **Test reorganization** (v1 exhaustive battery targets the strategy explicitly).

## Technical Context

- Dart 3.12; `packages/myenc_core` is pure Dart — no Flutter, no `dart:io` — strategies must
  stay pure functions (FR-004).
- The `.latch` v1 layout is frozen (`docs/FORMAT.md` normative): `codec_freeze_test.dart` and
  the golden vectors are never edited to make a test pass — they are the acceptance criterion.
- Baseline gates: core 86 / adapters 36 / app 143 tests; `dart format` +
  `flutter analyze --no-pub` + `flutter test` in all three packages; Android gate N/A (no
  Kotlin touched).
- Branch: `refactor/core-versioned-codec-seam`, cut from `develop` after PR #61 merges.

## Complexity Tracking

| # | Complexity introduced | Why acceptable / how justified |
|---|----------------------|-------------------------------|
| 1 | Strategy abstraction at one version | Paid for by the proof-of-neutrality argument (Decision 4): this is the only moment the extraction can be proven neutral with unedited freeze/golden pins |
| 2 | Committed binary fixtures (two corpora) | They are the neutrality evidence, not convenience fixtures — must pass unedited by design (SC-001/002) |
| 3 | Public strategy contract in core | Required by the totality test; keeps the registry pure; BL-001 capability checks key off the same `FormatVersion` entries later |
| 4 | Four-commit discipline | Separates "mechanical move" from "new machinery" so each is auditable independently; review burden is the point |
